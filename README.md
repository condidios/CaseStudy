How to play:
-The player will be able to drop the block if he/she clicks on the block hovering on top. That block will drop down to the grid.
-Adjecent segments with the same colors will pop and give the player score.
-Other segments left in a block after a pop operation will expand to fill the block.
-If there are any pop cases after expanding they are handled too.
-There are 3 levels.
-In third level player has a hammer to use. If the player clicks on the hammer button and then on a block on the grid, that block will be deleted.
-Hammered blocks segments do not add up to the score of the player.


Known bugs:
-Sometimes problems happen with popping algorithms when there are long chain reactions.
-At the inital level setup blocks are created randomly and they may have cases that need popping. They are not handled at the initalization of the level and that creates a picture where there are available blocks to be popped but they are not popped. All of this
cases happen at once if there is an interaction with one of these blocks with the player places block.
